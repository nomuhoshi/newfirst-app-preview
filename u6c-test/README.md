## 先做隔离（避免覆盖日常进度、避免同步到云端）
1. 用**独立浏览器配置**（Chrome：新建个人资料 / iPhone：Safari 隐私浏览或另一个浏览器）打开预览。
2. **不要登录**，全程游客模式。已登录时无法导入，也会同步到测试云。
3. 预览的存储键带 `u6c:` 前缀，与第一版和其他预览互不覆盖；独立配置是双保险。

## 导入
1. 把 `unlock-U1-U5-to-U6L1.json` 存到手机/电脑（iPhone：存进「文件」App）。
2. 预览「我的」→「备份学习记录」→「导入进度文件」→ 选该文件。
3. 弹出确认会写「34 个已完成关卡，0 XP」→ 确认导入。
4. 回「课程」：U6 单元首关 U6L1 可点开。

## 恢复 / 重来
- 想回到初始：浏览器清除该预览站点数据，或换新的独立配置，再导入一次即可（导入是合并，不会让进度变少）。
