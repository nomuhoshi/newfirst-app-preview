隐私说明

版本：2026-11-10（第一版发布候选，正式上线前还会更新）

碎片编程是一个免费的 Python 入门练习网站。我们只收集让它能用所必需的最少信息，没有广告，不做用户画像，不把你的信息卖给或交给任何人用于营销。

不登录（游客）时

  • 你的学习进度（XP、红心、连续天数、完成了哪些关、每关第一次完成的日期、声音和振动设置、写代码题的草稿）只保存在这台设备的浏览器里，不会上传。
  • 清除浏览器网站数据、或在“我的”页点“清除学习记录”，这些记录就会从这台设备上删除。

登录后

登录只用邮箱和一次性验证码，不需要设置密码。为了让你在换手机、换 iPad 后接着学，我们会在云端保存：

信息用途
邮箱地址发验证码、识别你的账号
学习进度：XP、完成次数、完成的关卡和日期、学习日期、红心、声音和振动设置多台设备之间同步进度
每台设备的随机编号（不含设备型号或个人信息）、导入过的游客记录的校验码多台设备同时学习时不重复加分、游客进度不重复导入
登录服务自动记录的登录时间和网络地址（IP）登录安全（例如防止有人反复请求验证码）。保留多久由登录服务商的日志设置决定，具体期限会在正式上线前补充到这里。

写代码题的草稿、运行的 Python 代码都只在你的设备上，不上传。Python 是在你的浏览器里运行的。

谁在帮我们处理这些信息

  • Supabase：提供登录和云端数据库，保存上面表格里的信息。数据存放的地区会在正式上线前补充到这里。
  • 邮件发送服务：把验证码发到你的邮箱，只用到你的邮箱地址。具体服务商确定后会写在这里。
  • GitHub Pages：托管这个网站的网页文件；和所有网站一样，托管方会看到访问请求（例如 IP 地址）。

网站没有使用任何统计、广告或追踪代码。

删除你的数据

  • 删除账号：登录后在“我的”页点“删除账号和云端记录”。你的账号和云端学习记录会从我们的数据库里删除，删除后无法恢复。云服务商可能还在它自己的定期备份里留有副本，这些副本按服务商的备份周期被覆盖，我们没法提前清除。
  • 只删这台设备上的：退出登录后点“清除学习记录”，或清除浏览器的网站数据。

未成年人

账号功能只面向年满 14 周岁的用户。不满 14 周岁的同学可以不登录使用全部课程，学习记录只保存在自己的设备上，不会上传。

联系我们

专门的隐私联系邮箱会在正式上线前补充到这里。

在那之前，可以在本项目的 GitHub 页面留言：github.com/nomuhoshi/newfirst-app/issues。那里的内容所有人都能看到，请不要写邮箱地址、验证码或任何个人信息。需要处理具体账号时，我们会在留言里另约私下联系的方式。
